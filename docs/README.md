## Как устроена версионность

Каждая **концепция** живёт как отдельный движок в `life_cube/engines/<имя>.py`
и описывается в `docs/engines/<имя>.md` по одной схеме: концепт (что хотим),
реализация (как сделано), крутилки, известные проблемы. Движки не трогают друг
друга: новый концепт — новый файл, старый остаётся работать. Выбор движка —
из панели в браузере, `life-cube serve --engine <имя>` или в коде
`Engine(rules="<имя>")`.

Версии программы — теги git `v0.x`; в `CHANGELOG.md` по каждой — что вошло.
Внутри одного движка настройки (гены, параметры мира) сохраняются пресетом
(кнопка «Скопировать пресет» в панели → JSON).
